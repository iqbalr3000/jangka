# 0001 — Node 24 LTS instead of Node 22

Date: 2026-10-23. Status: accepted.

## Context

The stack listed Node 22 LTS. At project start (Oct 2026) Node 22 is in maintenance and reaches end-of-life
in April 2027; Node 24 is the Active LTS line. Jangka is self-hosted, so the Node version ships inside every user's image.

## Decision

Use Node 24 LTS (`node:24-slim` base image, `engines.node >=24`, `.nvmrc` = 24).

## Consequences

- No forced runtime upgrade within months of the first release.
- All chosen dependencies (Hono, Drizzle, pg, pg-boss, Playwright, Vite) support Node 24.
- Next review when Node 26 becomes Active LTS.
