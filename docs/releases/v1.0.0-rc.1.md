First release candidate of Jangka 1.0. Not for production yet: please try the install and the core flows
below, and report anything that breaks.

### Highlights

- Write BRD, PRD and TSD documents with an assistant that interviews you first, then drafts each section
  live, and leaves sections empty instead of inventing content it wasn't given
- Built-in templates plus custom ones; a completeness check shows empty and partial sections at a glance
- Rewrite a section with an instruction and review the diff before accepting it
- Rich-text editor with Mermaid diagrams, edited as code and rendered live
- Traceability from BRD → PRD → TSD, with "needs review" flags when an upstream requirement changes
- Collections with group-based permissions, comments, assigned reviewers and approvals
- Section history, an audit log, full-text search and in-app notifications
- PDF and DOCX export with diagrams, a cover page and a requirements appendix
- Bring your own LLM key: Anthropic, OpenAI-compatible (incl. OpenRouter) or Gemini
- Email + password login, or SSO with Google or any OIDC provider
- One Docker image plus Postgres; no telemetry

### What to test

- Install from the compose file in the README and finish the setup wizard
- Draft a document from the interview, edit it, and export it to PDF and DOCX
- Generate a PRD from the example BRD and check the trace links
- On ARM machines (Apple Silicon, ARM servers): the same, natively on `linux/arm64`

### Install

```bash
mkdir jangka && cd jangka
curl -fsSLO https://raw.githubusercontent.com/iqbalr3000/jangka/v1.0.0-rc.1/docker/docker-compose.yml
export MASTER_KEY="$(openssl rand -base64 32)"   # keep it safe: it decrypts stored API keys
export JANGKA_VERSION=1.0.0-rc.1
docker compose up -d
docker logs jangka 2>&1 | grep "SETUP TOKEN"
```

Then open http://localhost:3000.

### Images

```bash
docker pull iqbalr3000/jangka:1.0.0-rc.1
docker pull ghcr.io/iqbalr3000/jangka:1.0.0-rc.1
```

Platforms: `linux/amd64`, `linux/arm64`.
